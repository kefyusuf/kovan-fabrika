# Code of Conduct — KOVAN

This project is modeled on the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We expect contributions to be **respectful, inclusive, and evidence-based**:
technical discussion runs on concrete evidence; personal attacks, belittling,
and harassment are not accepted. Experience level, language, nationality,
gender, belief, and other personal traits determine neither the value of a
contribution nor the tone norms.

## Expectations

- **Constructive:** criticism targets code and decisions; instead of
  un-actionable advice ("let's be more careful"), bring a runnable command or
  test (the project's mechanical-check norm).
- **Transparent:** mistakes, partial evidence, and uncertainty are not
  hidden — written down openly, like the ledger and log norms.
- **Boundaries:** code ownership is protected by m.2 — the producer does not
  approve.

## Enforcement

Report violations to the maintainers privately via GitHub. Maintainers apply
the Covenant's v2.1 scaled sanctions, from warning to permanent ban. If this
document conflicts with the project constitution (YONETISIM.md), the
constitution prevails.
